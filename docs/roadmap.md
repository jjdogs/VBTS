# Roadmap

[← Back to the README](../README.md)

## Done

1. ✅ Core blocks, split view, lessons
2. ✅ `using` and modules, all official devices, one-click fixes, share codes
3. ✅ Data: arrays, maps, options, function inputs and results, `<decides>`
   - 3.5 ✅ Responsive UI: phones, tablets, laptops, big screens, touch
   - 3.6 ✅ Edit Mode (Look panel) and the one-window editor
4. ✅ Your own types and several files
   - 4.1 ✅ Your own classes, structs and enums; access specifiers; style rule 6.2
   - 4.2 ✅ Multiple files: file tabs, classes and enums shared across files, whole-project share codes
5. ✅ Players & teams, UI widgets, positions and movement ([Phase 5 plan](plans/phase-5.md))
   - Since then, from Epic's API digests: events that send several values, respawn and send to
     lobby, random decimals and shuffle, prop animation, and more value events
6. ✅ Text ⇄ blocks: type directly in the Text view
7. ✅ Device data kept current from Epic's Verse API reference every week ([Verse API data](verse-api.md))

## In progress and next

- **Game-mode templates**: done so far: pop-up target gallery, team elimination, moving-platform
  parkour, shop menu.
- **VS Code extension**: on hold (web-only for now).
- Smaller items: a Sleep block that takes a value, and the [known quirks](blocks-and-verse.md#known-quirks).
